# news-monitor Remotion Demo

这是一个独立的 Remotion 演示项目，不属于主 Web 应用。

## 运行预览

```powershell
cd demos/news-monitor-remotion
npm install
npm run studio
```

打开 Remotion Studio 后选择 `NewsMonitorDemo`。

## 渲染视频

```powershell
npm run render
```

输出文件：

```text
demos/news-monitor-remotion/out/news-monitor-demo.mp4
```

## 内容

视频演示从 GitHub 获取项目到实际使用：

1. clone 仓库
2. 安装依赖和准备 `.env`
3. 双击 `start-dev.cmd`
4. 导入高价值信源
5. 总编台展示“正在升温 / 已被确认 / 我的订阅”
6. 用队列和 AI 状态命令做本地诊断
