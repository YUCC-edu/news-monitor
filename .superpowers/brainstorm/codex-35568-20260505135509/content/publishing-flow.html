一句话到公众号草稿箱的交付链路

这是我目前理解的完整能力边界：外部 agent 发起，News Monitor 负责选题、成文、配图、上传和入草稿箱。

Target Workflow
1. Agent 指令
“写最近热点 / 最新研究解读，推送到公众号草稿箱”
2. 选题 brief
从热点、论文、收藏、关键词里挑最强信号
3. 个人 IP 成文
标题、结构、事实链、观点、引用、CTA
4. 自动配图
封面图 + 章节图，生成后上传微信素材库
5. 微信草稿
HTML 排版、图片 media_id、草稿箱可直接审核发布
A

Agent API 优先

做一个稳定 HTTP/CLI 能力：Codex 这类工具调用后直接生成公众号草稿。分类页作为内容发现和人工复核界面同步优化。

B

页面工作台优先

先把分类页和报告页做成可视化操作台，再把同一套动作暴露给 agent 调用。
