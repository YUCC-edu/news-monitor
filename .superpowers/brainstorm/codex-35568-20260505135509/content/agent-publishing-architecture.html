Agent API 优先的交付架构

目标是把高成本判断固定成可复用规则，把图片生成放到可替换 provider，保证 Codex/image2 和 HTTP 图片服务走同一条入草稿链路。

Boundary: Codex / News Monitor / WeChat
External Agent

Codex

一句话触发任务

可用 image2 生成图片

把图片文件/URL 回传项目

News Monitor

固化工作流

内容选择：只查已入库热点、论文、收藏、关键词
风格生成：历史样本 + 固定个人 IP 配置
图片任务：cover + hero/section brief，默认不烧项目图片 API
草稿组装：微信 HTML、图片上传、草稿箱创建、attempt 记录
Delivery

微信公众号

永久素材库图片

可审核草稿

失败可重试，不自动群发

Cost Controls

  • 默认只用数据库事实材料，不临时联网。
  • 风格档案使用压缩规则，不反复塞样本。
  • Codex 场景图片由 agent/image2 完成，项目只处理回传和上传。

Explicit Tradeoff

  • Codex 模式会有一次“图片任务回传”握手，不是单个 HTTP 请求全自动。
  • 无外部图片 provider 时，非 Codex 场景只能生成图文 brief 或使用默认封面。
